How to use these — firewall-by-firewall instructions
  • FortiGate: Security Fabric → External Connectors → Create New → IP Address Threat Feed, then paste the URL.
  • Sophos Firewall (SFOS 21.0+): Active threat response → Third-party threat feeds → Add → type IPv4, action Block, paste the URL.
  • SonicWall (SonicOS 7): Object → Match Objects → Dynamic External Object → protocol HTTPS, paste the URL; use the created address group in a rule.
  • Palo Alto: Objects → External Dynamic Lists → add as an IP List.
  • Cisco Secure Firewall (FMC): Objects → Object Management → Security Intelligence → Network Lists and Feeds → add a feed URL.
  • Check Point (R81+ SmartConsole): Security Policies → Threat Prevention → Custom Policy Tools → Indicators → New → External IOC Feed, paste the URL.
  • pfSense (pfBlockerNG): Firewall → pfBlockerNG → IPv4 → add the URL as a new source.
  • OPNsense: Firewall → Aliases → add a URL Table (IPs) alias.
The list is plain text, one IP or CIDR per line, refreshed each pipeline run and with whitelisted IPs removed automatically. Most firewalls re-poll on their own schedule (e.g. every 5–60 min).
